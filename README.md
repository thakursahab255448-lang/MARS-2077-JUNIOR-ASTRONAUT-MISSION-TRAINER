# Project Description
MARS 2077 is an interactive educational space exploration and survival simulation game inspired by the NASA Space Apps Challenge theme "Build a Junior Astronaut Mission Trainer".

The project aims to help young learners understand astronaut life, space exploration, resource management, and engineering challenges through interactive gameplay.
